# SEO-стратегия KinderCore

## Цель

Сделать сайт понятным поисковым системам и потенциальным клиентам — организациям, которые проводят занятия. Техническая оптимизация помогает корректной индексации, но сама по себе не гарантирует высоких позиций.

## Структура на старте

1. Главная — что такое KinderCore, для кого продукт и в чём ценность.
2. Возможности — только функции, подтверждённые актуальной версией продукта.
3. Для организаций — сегменты и сценарии, если они описаны честно и полезно.
4. FAQ — ответы на реальные вопросы, без искусственного повторения ключевых слов.
5. Контакты/заявка — понятный способ связаться, с минимальным сбором персональных данных.

Не создавать тонкие страницы под каждый ключевой запрос и не копировать один и тот же текст для разных отраслей.

## Технический чек-лист

- Уникальные и описательные `title` и meta description.
- Один ясный основной `h1` на страницу и логичная иерархия подзаголовков.
- Семантический HTML и работа с клавиатуры.
- Мобильная адаптация и быстрая загрузка.
- Оптимизированные изображения с осмысленным alt там, где изображение несёт смысл.
- Читаемые URL.
- `robots.txt` и `sitemap.xml`.
- Canonical только после выбора канонического домена/URL.
- Корректные статусы страниц и отсутствие битых ссылок.
- Open Graph для аккуратного отображения ссылок в соцсетях.
- Не добавлять структурированные данные, которые не соответствуют видимому содержимому.

## Контент и доверие

- Объяснять продукт простым языком и показывать реальные сценарии.
- Не выдумывать отзывы, результаты, количество клиентов, партнёрства и сертификаты.
- Разделять доступные и планируемые функции.
- Не заявлять полное соответствие 152-ФЗ без проверки.
- Не утверждать наличие банковских интеграций до подтверждения.

## После публикации

После выбора домена подключить Google Search Console и Яндекс Вебмастер. Отслеживать индексирование, технические ошибки, реальные запросы и переходы. Обновлять контент на основе вопросов пользователей и подтверждённых возможностей продукта.
