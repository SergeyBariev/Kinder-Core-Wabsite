# KinderCore Website

Отдельный репозиторий публичного сайта KinderCore. Проект изолирован от CRM и KinderCore AI Company.

## Статус

Репозиторий создан; исходный код сайта ещё не добавлен. Разработка начинается с минимального адаптивного сайта с технической SEO-основой.

## Границы проекта

- Не изменять репозиторий `SergeyBariev/kinder-crm`, его код, миграции, Supabase, CI/CD, ветки, PR или данные.
- Не подключать сайт напрямую к базе CRM.
- Не смешивать сайт с проектом `kinder-ai-agents`.
- Не подключать платные сервисы, тарифы или домены без отдельного согласования.
- Не использовать реальные персональные данные детей и родителей в демо, тестах или репозитории.
- Не заявлять функции CRM, банковские интеграции или юридическое соответствие, пока они не подтверждены.
