# KinderCore Website

Публичный сайт KinderCore. Отдельный репозиторий, изолированный от CRM и KinderCore AI Company.

## Текущая структура

- Главная на русском: /
- Полноценная английская версия: /en/
- Отдельная страница партнёрам: /partners/
- English partner page: /en/partners/
- Страница статуса документов о персональных данных: /privacy.html
- Статические CSS/JS без сторонних SDK и аналитических счётчиков.

## Важные ограничения перед включением заявок

Форма подготовлена по согласованным полям, типам обращений и обязательному согласию, но намеренно отключена. Для активации нужны: корпоративная почта KinderCore, подтверждённый адрес-получатель, безопасный почтовый транспорт, проверка доставки, заполненные сведения об операторе, юридически утверждённые политика и текст согласия, а также проверка применимых требований 152-ФЗ и статуса уведомления Роскомнадзора. Страница privacy.html прямо сообщает, что документ пока не является утверждённой политикой.

Собственная аналитика не включена. Не активировать D1-сбор, пока не закрыты правовые и инфраструктурные вопросы локализации и обработки технических данных.

## Границы проекта

- Не изменять репозиторий SergeyBariev/kinder-crm, его код, миграции, Supabase, CI/CD, ветки, PR или данные.
- Не подключать сайт напрямую к базе CRM.
- Не смешивать сайт с проектом kinder-ai-agents.
- Не подключать платные сервисы, не покупать домен и не менять DNS без отдельного согласования.
- Не использовать реальные персональные данные детей и родителей.
- Не заявлять функции CRM, банковские интеграции или юридическое соответствие, пока они не подтверждены.
- Не выдумывать отзывы, логотипы клиентов, цифры, сертификаты и результаты.
