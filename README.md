# KinderCore Website

Публичный многостраничный сайт KinderCore на Cloudflare Pages. Русская версия — основная; английская версия подготовлена в отдельном каталоге `/en/`.

## Структура

- `/` — главная: позиционирование, ключевые направления CRM, аудитория и модель оплаты.
- `/features.html` — возможности CRM.
- `/how-it-works.html` — ежедневный процесс работы.
- `/payments.html` — прозрачное объяснение вознаграждения KinderCore.
- `/faq.html` — частые вопросы.
- `/partners/` — отдельная партнёрская страница.
- `/en/` и страницы в `/en/` — английская версия.
- `docs/legal/PERSONAL_DATA_POLICY_DRAFT.md` — юридический проект политики, не готовый к публикации.

## Разработка и границы

- Сайт изолирован от `SergeyBariev/kinder-crm` и `SergeyBariev/kinder-ai-agents`.
- Не подключать сайт к CRM API, Supabase или базам CRM.
- Не публиковать реальные персональные данные, скриншоты с данными пользователей, секреты, отзывы и метрики без подтверждения.
- Не включать аналитику и запись событий в D1 до отдельной юридической и технической проверки.
- Форма обращения подготовлена в интерфейсе, но отключена: корпоративная почта, безопасная схема доставки и юридические документы ещё должны быть готовы. Отключённая форма не принимает и не сохраняет введённые данные.
- Не показывать сообщение об успешной отправке, пока не реализовано требуемое подтверждение доставки.
- Не подключать собственный домен и не менять DNS в рамках этой ветки.

## Проверки

GitHub Actions workflow `.github/workflows/validate-site.yml` запускает статические проверки HTML и локальных ссылок. До публикации дополнительно необходимы визуальная проверка desktop/mobile, проверка доступности и ручная приёмка владельцем.

## Позиционирование

KinderCore — место, где организация управляет всем, что связано с детским центром. CRM не имеет ежемесячной абонентской платы. Вознаграждение KinderCore связано с платежами организации: 0,3% от платежей через СБП и 1,0% от платежей картой. Организация остаётся получателем денег за занятия; банковские комиссии оплачиваются отдельно по договору организации с банком.
